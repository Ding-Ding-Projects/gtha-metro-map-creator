Getting started

Open the editor. On first run a three-step setup asks how to start (GTHA template, blank map, or your saved map), then your language and theme, then shows the tools. You can skip it, and rerun it from Settings.

The workspace has three parts: the Lines and search panel on the left, the map in the middle, and the Inspector on the right. On a narrow screen the panels stack under the map.

Pan by dragging empty space with the Select tool, by holding Space while dragging, or with the middle mouse button. Scroll to zoom around the pointer. F fits the whole map.

The GTHA template

The template contains TTC Lines 1, 2, 4, 5 and 6, the planned Ontario Line, GO Lakeshore West, Lakeshore East, Kitchener, Milton, Barrie, Richmond Hill and Stouffville, UP Express, and simplified Hurontario and Hamilton LRT lines.

It is a schematic: positions are grid units chosen for legibility, not geography. Station lists for regional and LRT lines are shortened, line colours are approximate, and planned lines use the dashed style. Service status is not tracked. Check TTC and Metrolinx for real service.

Some corridors use bend points instead of stations, so several GO lines can leave Union together and split later.

Stations

With the Station tool, click empty grid to add a stop, or click a line segment to insert a stop into it. Every line using that segment gets the new stop.

Select a station to edit its name, Chinese name, label position and interchange style. Interchange is automatic when two or more lines serve the stop; you can force it on or off. Shift-click selects several stations, which you can align horizontally or vertically, move together, or delete.

Drag to move. With snapping on, stations land on whole grid units. Arrow keys nudge by one unit, or five with Shift.

Lines and segments

Pick a line in the Lines panel to make it active, or press New line. With Draw line, click stations in order to extend the active line. Clicking empty space adds a new stop there; holding Alt adds a bend point instead.

Each segment has at most one bend. Select a segment to switch between diagonal first and straight first, insert a station, or erase it. Erasing a middle segment splits the line in two.

Line settings: name, Chinese name, colour, width, style (solid, dashed for planned, or regional rail with a white centre stripe), order, direction and visibility. Lines that share a pair of stops are drawn side by side. The first line drawn on a shared segment sets its bend.

Labels and languages

Automatic labels test eight positions around a stop and take the one crossing the fewest lines and neighbouring stops. You can pin any of the eight positions per station.

The interface and map labels follow the language setting: English, Cantonese, or bilingual. In Cantonese mode a stop shows its Chinese name when it has one; bilingual mode shows both. The template ships English names only, so add Chinese names yourself.

Free text labels come from the Label tool. Edit their text and size in the Inspector.

Finding stations

Type in Find station. Plain text mode matches any part of a name. Regular expression mode uses JavaScript Unicode patterns, for example ^St or (Park|Square)$. Ignore case is on by default. Invalid patterns show the error. Click a result to select and centre it.

Regex builder

Open Regex builder under the search box. It edits the same search field, so the search and the builder always agree.

  • Tokens: buttons insert start and end anchors, character classes such as \d and \p{L}, sets, groups, named groups, alternation, quantifiers, lookahead and lookbehind, and back references. With text selected, a group token wraps the selection.
  • Escape as literal text turns what you typed into a pattern that matches it exactly.
  • Flags: Ignore case, Multiline (m) and Dot matches newline (s). Unicode mode is always on. The full pattern with flags is shown next to the engine name.
  • What the pattern means explains each part in plain words.
  • Test text highlights matches. It uses the station names on the current map until you type your own text, up to 5000 characters, and stops counting at 500 matches.
  • Groups lists numbered and named groups from the first match. Replace with previews a replacement using $1 or $<name>.
  • Pattern library: start from a built-in pattern, or name and save your own (up to 30, kept in this browser).

The engine is the JavaScript regular expression engine in your browser. Other engines' syntax, such as possessive quantifiers or atomic groups, is not available, and patterns over 200 characters are refused.

Map check

The Map check panel updates on every change and lists stations that no line serves, lines with fewer than two stops, names used more than once, and stations sharing one position. Click an item to jump to it.

Saving, import and export

Every change autosaves in this browser's local storage. Nothing is uploaded. Undo and redo keep the last 200 steps for this session.

Export offers SVG (vector, with title and optional legend), PNG (rendered at up to twice the size), and JSON (the editable map). Open JSON from the Export menu or drop a file on the editor. Files over 5 MB or with an unexpected shape are refused and your current map is kept.

Settings

Language, theme, label size, grid visibility, snapping, export legend and sound effects are saved in this browser. Sound effects are short tones for actions; turn them off here. Reset settings returns everything to defaults. Reset all labels to automatic clears pinned label positions.

Keyboard shortcuts

V Select, S Station, L Draw line, T Label, E Erase, F Fit, Delete delete selection, Ctrl+Z undo, Ctrl+Y or Ctrl+Shift+Z redo, arrows nudge, Esc clears selection.

Desktop app

Download GTHA-Metro-Map-Creator-<version>-portable.exe from the project's GitHub releases and run it. It is one file with nothing to install, and it works with no internet connection: the editor, this documentation and the project page are all inside it.

  • File: New map from the GTHA template (Ctrl+N), New blank map, Open map (Ctrl+O), Open recent, Save (Ctrl+S), Save as, Export SVG and Export PNG. Exports ask where to save.
  • Unsaved changes: closing or starting a new map asks whether to save a map that came from a file. Your work is also kept automatically inside the app.
  • View: Editor (Ctrl+1), Guides and documentation (Ctrl+2) and Project home (Ctrl+3), plus zoom and full screen.
  • Opening a .json map file with the app loads it.

The app is not code signed, so Windows SmartScreen may warn the first time you run it. Choose More info, then Run anyway, if you trust the download.

Host it on your network

You can run the editor as a small web server so other devices on your home network can open it. It needs Docker Desktop.

With the setup wizard

Download GTHA-Metro-Map-Creator-Server-Setup-<version>-portable.exe from the releases and run it. It walks through five steps: check Docker, choose a port, download the image, start the server, and open it on your network. When it finishes it shows the network address, such as http://192.168.1.20:8080/, with Open and Copy buttons. It remembers your choices if you close it and run it again, and it can stop the server.

With host.bat

From a copy of the project, run host.bat and choose a mode, or pass it directly:

  • host.bat --detached downloads the image, starts the server in the background, waits for the health check and prints the network address.
  • host.bat --logs does the same, then shows a menu: F follows logs, T shows the last 50 lines, S shows status, R restarts, X stops the server and Q leaves with the server still running.
  • host.bat --stop stops the server.

Set GMMC_PORT to use another port (default 8080) and GMMC_TAG to pin an image version (default latest).

With Docker Compose

The image is ghcr.io/ding-ding-projects/gtha-metro-map-creator. Run docker compose up -d next to the project's compose.yaml. The container runs nginx as a non-root user on port 8080 with a read-only file system, and answers /healthz for health checks.

If other devices cannot connect, allow the port through Windows Firewall. The server has no sign-in, so only run it on a network you trust.

Map file format

A map is JSON with version: 1, title, stations (an object keyed by id, each with name, nameZh, x, y, label, interchange), lines (each with name, color, width, style, visible, path, bends), and labels. A path entry is a station id or a bend point written @x,y. bends maps a segment index to late for straight first.
