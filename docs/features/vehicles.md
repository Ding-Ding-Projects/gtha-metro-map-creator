# Vehicles

Each route can list the vehicle types that run on it. This is descriptive data for maps and
exports; it does not change timetables.

## Data

`line.vehicles` is an optional array of up to 20 entries (see [map-format.md](map-format.md)):

| Field | Meaning |
| --- | --- |
| `maker`, `model` | Free text, up to 60 characters each. At least one is required. |
| `kind` | `bus`, `articulated` (articulated bus), `doubleDecker`, `lrv` (light rail vehicle), `subway` (subway car), `regional` (regional train) or `other`. |
| `count` | Optional number of vehicles, 1 to 9999. |
| `note` | Optional, up to 120 characters. |

Maps without the field open as before. The built-in template lists no vehicles, because no public
source for each route's fleet has been checked.

## Editing

Select a route and use **Vehicles** in the inspector. Each vehicle is a card with a drag handle,
an edit button and a delete button. The edit button opens the fields:

- **Maker** and **Model** are autocomplete fields with a suggestion menu. Choosing a known model fills in
  the maker and the type. Any other text is accepted.
- **Type** is a dropdown menu with an icon for each kind.
- **Number of vehicles** is a stepper.
- **Note** is free text.

Reorder by dragging the handle, or focus the handle and press the up or down arrow key. **Add vehicle**
appends a card. Every change is one undo step. All controls work with the keyboard, show a focus ring and
are labelled in English and Cantonese.

### Suggestions

The suggestion list is a convenience, not a fleet record: New Flyer Xcelsior XD40, XD60 and XE40;
Nova Bus LFS and LFS Articulated; Alexander Dennis Enviro500; Proterra ZX5; BYD K9M; Alstom (Bombardier)
Flexity Outlook; Alstom Citadis Spirit; Bombardier Toronto Rocket and BiLevel Coach; Siemens Charger;
Stadler FLIRT.

## Where vehicles appear

- The route list shows a short summary under each route, for example `New Flyer Xcelsior XD60 +1`.
- The trip planner shows the first vehicle of a route in each ride leg.
- Exports can add a vehicles column to the legend. Turn on **Show vehicles in the export legend** in
  Settings (off by default); it needs **Show legend in exports**.
