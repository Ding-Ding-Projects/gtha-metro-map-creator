# Template data sources

`site/app/gtha-transit-data.js` is generated by `make-transit-data.mjs` from the two extracts in
`sources/`. Do not edit the generated file by hand.

| File | Source | Licence |
| --- | --- | --- |
| `sources/station-coordinates.json` | OpenStreetMap, via the Overpass API, November 2026: railway stations, halts and light-rail stops in the GTHA, matched to template stations by name and line type. 21 stations under construction or missing a matching node use the closest named OpenStreetMap feature. | ODbL, © OpenStreetMap contributors |
| `sources/viva-routes.json` | York Region Transit GTFS feed (`google_transit.zip`), service 1 November to 19 December 2026: VIVA Blue, Purple, Orange and Yellow, the most common stop pattern of each, and weekday headways (peak 7 to 9 a.m., midday 10 a.m. to 3 p.m., one direction, scheduled departures divided by the window). | York Region Transit open data |

The generator merges a VIVA stop into a template station within 300 m, gives other stops a
schematic position from a least-squares fit, and writes frequencies and a source note on each
route.

```bash
node scripts/data/make-transit-data.mjs scripts/data/sources/station-coordinates.json scripts/data/sources/viva-routes.json
```

## Population for coverage and ridership

`site/app/gtha-population.js` is generated by `make-population.mjs`; do not edit it by hand. The
script downloads its sources into a temporary folder you name, outside the repository.

```bash
node scripts/data/make-population.mjs <temp dir>
```

| Source | URL | Licence |
| --- | --- | --- |
| Statistics Canada, 2021 Census of Population, table 98-10-0015-01, "Population and dwelling counts: Canada, provinces and territories, census subdivisions and dissemination areas" | `https://www150.statcan.gc.ca/n1/tbl/csv/98100015-eng.zip` | Statistics Canada Open Licence |
| Statistics Canada, 2021 digital boundary file for dissemination areas (layer 12 of the public map service) | `https://geo.statcan.gc.ca/geo_wa/rest/services/2021/Digital_boundary_files/MapServer/12/query` | Statistics Canada Open Licence |

Retrieved 15 November 2026. The Census Profile download pages on `www12.statcan.gc.ca` sit behind a
bot check and were not used.

Processing: keep dissemination areas in the Toronto, Peel, York, Durham, Halton and Hamilton census
divisions (3520, 3521, 3519, 3518, 3524, 3525). The boundary service returns each polygon in
WGS 84, simplified by about 30 m; the point for an area is its area-weighted polygon centroid.
Areas with zero population are dropped. Coordinates are rounded to 4 decimals (about 10 m).

Totals match the census division rows of the same table exactly: Toronto 2,794,356, Peel 1,451,022,
York 1,173,334, Durham 696,992, Halton 596,637, Hamilton 569,353, sum 7,281,694. That is 9,378
points from 9,399 areas (21 have no residents). The file is 225 KB, so no grid aggregation is
needed.

Employment by small area (place of work) is not available as open data at this level, so jobs are
not included.
