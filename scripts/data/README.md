# Template data sources

`site/app/gtha-transit-data.js` is generated by `make-transit-data.mjs` from the two extracts in
`sources/`. Do not edit the generated file by hand.

| File | Source | Licence |
| --- | --- | --- |
| `sources/station-coordinates.json` | OpenStreetMap, via the Overpass API, November 2026: railway stations, halts and light-rail stops in the GTHA, matched to template stations by name and line type. 21 stations under construction or missing a matching node use the closest named OpenStreetMap feature. | ODbL, © OpenStreetMap contributors |
| `sources/viva-routes.json` | York Region Transit GTFS feed (`google_transit.zip`), service 1 November to 19 December 2026: VIVA Blue, Purple, Orange and Yellow, the most common stop pattern of each, and weekday headways (peak 7 to 9 a.m., midday 10 a.m. to 3 p.m., one direction, scheduled departures divided by the window). | York Region Transit open data |

The generator merges a VIVA stop into a template station within 300 m, gives other stops a
schematic position from a least-squares fit, and writes frequencies and a source note on each
route.

```bash
node scripts/data/make-transit-data.mjs scripts/data/sources/station-coordinates.json scripts/data/sources/viva-routes.json
```
